# Módulo Kotlin – ControlGastos

## Función
Este módulo contiene la lógica de programación de ControlGastos. Su función es procesar y administrar la información relacionada con los ingresos y gastos de los usuarios.

## Funcionalidades principales
- Representar los datos de los gastos mediante modelos.
- Manejar información como identificador, descripción, monto, categoría y fecha.
- Registrar nuevos gastos.
- Buscar gastos por su identificador.
- Actualizar gastos existentes.
- Eliminar gastos.
- Validar que las descripciones y los montos sean correctos.
- Realizar operaciones relacionadas con los ingresos, gastos y balance.

## Tecnologías utilizadas
- Kotlin.
- Coroutines.
- Funciones suspend.
- Modelos de datos.

## Importancia del módulo
Permite organizar la lógica de la aplicación y separar el procesamiento de los datos de las interfaces visuales.
