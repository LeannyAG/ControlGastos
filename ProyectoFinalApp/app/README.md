\# Módulo Android – ControlGastos



\## Función

Este módulo permite conectar la lógica de Kotlin con Android y proporciona las interfaces visuales para que el usuario interactúe con la aplicación.



\## Funcionalidades principales

\- Mostrar la pantalla de registro de usuario.

\- Registrar ingresos y gastos.

\- Mostrar los movimientos registrados.

\- Filtrar ingresos y gastos.

\- Mostrar el resumen financiero.

\- Consultar el balance disponible.

\- Buscar gastos por ID.

\- Editar y eliminar gastos.

\- Conectar las interfaces con la base de datos.



\## Tecnologías utilizadas

\- Android Studio.

\- Kotlin.

\- XML.

\- RecyclerView.

\- Room Database.

\- Coroutines.

\- Android SDK.



\## Importancia del módulo

Permite que el usuario utilice las funcionalidades de ControlGastos desde un dispositivo Android mediante sus interfaces.
