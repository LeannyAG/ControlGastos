# ControlGastos

## Descripción
ControlGastos es una aplicación móvil desarrollada para Android utilizando Kotlin. Su finalidad es facilitar la administración de las finanzas personales mediante el registro y control de ingresos y gastos.

## Funcionalidades principales
- Registro de usuario.
- Registro de ingresos y gastos.
- Clasificación de gastos por categorías.
- Consulta y filtrado de movimientos.
- Resumen de ingresos y gastos.
- Consulta del balance disponible.
- Búsqueda de gastos por ID.
- Edición y eliminación de gastos.
- Almacenamiento de información mediante Room Database.

## Tecnologías utilizadas
- Kotlin.
- Android Studio.
- XML.
- Room Database.
- RecyclerView.
- Coroutines.

## Funcionamiento
El usuario registra sus datos personales y posteriormente puede registrar ingresos y gastos, consultar sus movimientos, editar o eliminar gastos y revisar su balance financiero.

La información se almacena localmente mediante Room Database para conservar los registros.

## Estructura del proyecto
- Kotlin: contiene la lógica y el manejo de datos.
- Android: contiene las interfaces visuales y la interacción con el usuario.
